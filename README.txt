Included:

- Dark/light mode (saved in browser localStorage)
- Responsive mobile navigation

- Dynamic typing animation
- Scroll-to-top button
- FAQ accordion

- SEO titles, descriptions, canonical tags, Person structured data
- robots.txt and sitemap.xml

IMPORTANT BEFORE PUBLISHING:
1. Replace https://your-domain.com in canonical tags, JSON-LD, robots.txt and sitemap.xml with your real domain.
2. Replace your-email@example.com with your real email address.
3. Add your real portrait at assets/images/profile.jpg and update the portrait-placeholder in index.html to use it.
4. Replace the sample project cards in projects.html with real projects, screenshots and working links. They are clearly marked as starter examples.
5. Add your actual CV PDF at assets/cv/nabil-rahman-cv.pdf. The download links already point to this path.
6. Add real social profile links when available.
7. Submit sitemap.xml in Google Search Console after deployment.

Run locally:
Open index.html in a browser, or use VS Code Live Server.
